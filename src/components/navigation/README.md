# Navigation Components

## Purpose

This folder contains all components responsible for the website's navigation.

Every page on the website will use these components.

## Files

### Navbar.tsx
The main navigation bar displayed at the top of every page.

### Navbar.css
Styles for the desktop navigation bar.

### MobileMenu.tsx
The navigation menu displayed on mobile devices.

### MobileMenu.css
Styles for the mobile navigation menu.

### NavLinks.tsx
Contains all navigation links shared between desktop and mobile.

### Logo.tsx
Displays the Teens Connect Africa logo.

### index.ts
Exports all navigation components from one place.

## Features

- Responsive
- Sticky navigation
- Mobile menu
- Active page highlighting
- Smooth scrolling
- Accessible
- Reusable
